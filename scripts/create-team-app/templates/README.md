## Boundary

This app lives in `team-apps/{{name}}/` and reaches core data **only through a
core app's published, versioned API** (for refunds: `/api/v1/refunds`, see
`apps/refunds-dashboard/README.md`). It must never import from `apps/**`
(relative paths and `@/` aliases included) or open a core app's database;
`pnpm lint` rejects those imports. Use `@acme/audit-log` for changes to this
app's own data and `@acme/auth-guard` for access checks. See PLAYBOOK.md
section 6.
